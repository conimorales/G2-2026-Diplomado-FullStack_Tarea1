Entendimiento de como se clasifica una solicitud

Cada tipo de solicitud tiene una clasificación

🛠️ Soporte base
El sistema ya existe y tiene un error
  • Es sin costo
  • Lo solicita 1 área
  • Es inmediato / Correctivo
  • No es formal
  • ❌ No requiere Cotizaciones, OC, Factura y CER
CAPEX: No aplica
⚡ Mejora Menor Directa
Cambio o ajuste pequeño sin costo adicional
  • Es sin costo
  • Lo solicita 1 área
  • Requiere pocos días el cambio
  • No es formal
  • ❌ No requiere Cotizaciones, OC, Factura y CER
CAPEX: No aplica
🔧 Mejora Menor (OPEX)
El sistema ya existe y se crea solicitud de mejora
  • Presupuesto mínimo
  • Lo solicita 1 área o involucra a más áreas
  • Requiere planificación y seguimiento
  • ✅ Requiere Cotizaciones, OC, Factura y CER
CAPEX: No aplica
🚀 Nuevo Proyecto (CAPEX)
El sistema ya existe y requiere cambio mayor, o no existe
  • Inversión relevante
  • Involucra varias áreas
  • Requiere semanas o meses
  • ✅ Requiere Cotizaciones, OC, Factura y CER
CAPEX: Inversión de capital Genera activos o capacidades nuevas para la organización.
